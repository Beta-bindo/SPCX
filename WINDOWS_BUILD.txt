交易助手 — Windows 打包说明
================================

【在 Windows 10/11 上操作】

若 build.bat 双击乱码或闪退：
  1. 先双击 check_env.bat 或 检查环境.bat
  2. 未装 Python：去 python.org 安装，勾选 Add to PATH
  3. 再双击 build.bat（纯英文输出，避免 CMD 编码乱码）

方式 A：仅 exe（最快）
  1. 删除旧解压目录，重新解压 TradeAssistant-WindowsBuild.zip
  2. 确认 build.bat 开头显示 "Windows Build v8"（输出到 TEMP 目录，避免 exe 被锁）
  3. 双击运行 build.bat（需联网，首次约 5–15 分钟）
  4. 完成后得到 dist\TradeAssistant.exe
  5. 双击 TradeAssistant.exe 即可使用（无需安装 Python）

方式 B：安装包（需 Inno Setup）
  1. 先完成方式 A 的 build.bat
  2. 安装 Inno Setup 6: https://jrsoftware.org/isinfo.php
  3. 双击 build_installer.bat
  4. 得到 installer_output\TradeAssistant_Setup_1.0.0.exe
  5. 将此安装包发给用户双击安装

【配置与数据位置】
  C:\Users\你的用户名\.xau_assistant\config.json

【换电脑】
  API 密钥不会随 exe 带走，需重新填写或拷贝上述文件夹。

【MT5】
  需在本机安装 Exness MetaTrader 5 终端并保持登录。
